# False Nine

A career management game about a Russian footballer who is good, works hard, and never
makes it — and about what he builds instead.

Python 3.12 + pygame-ce. One career, ages 16–32, 3–5 hours.

## Getting started

```bash
uv sync
uv run false-nine
```
